先用 node scripts/we.mjs inspect KEY 查看选样快照。每个槽只引用用户实际选择的组件。下列为计划结构示例，key 与选择器必须替换为实际快照中的值：

```json
{"name":"校园活动回顾","parts":{
  "layout":{"key":"整页快照编号","target":"[data-component='component-4']","remove":["[data-component='component-9']"]},
  "heading":{"key":"标题快照编号","target":"span.headline"},
  "note":{"key":"卡片快照编号","target":".note-content"},
  "divider":{"key":"分割线快照编号"},
  "ending":{"key":"文末快照编号"}
}}
```

只写选用的角色。target 是唯一的内容容器，保留其标签和行内样式，替换它的子节点。整页选一个能容纳完整稿件的块级正文容器（如 div 或 section，不要用 p/span 塞整篇）。按实际结构清除其外面残留的样例标题、示例日期、联系方式、二维码等；保留用户选定的装饰。remove 使用唯一选择器，先删后填。heading 用于每个二级标题，note 用于显式提示块，divider 替换 Markdown 水平线，ending 追加一次。标题和卡片的目标必须能容纳对应内容；只处理一次的特殊段落可以先生成独立的本期变体。复杂多栏底版不能稳定映射到单个正文槽时，说明限制并让用户选择其中的区块，不能声称已完整套用。交互 SVG 仅作为静态素材预览，依赖点击或动画才可见的内容不要作为必要信息。

node scripts/we.mjs pack 计划.json 新模板包.json 把清理后的 HTML 和插槽绑定写入单个文件，不覆盖旧文件。render 只读包，不读选样记录，换电脑只需传包与新稿。在用户要求长期保存以前，计划和包可放本期工作目录。检查 preview.html：正文是否完整、原样例是否清干净、固定槽是否重复、外链图片是否正常。不把二维码/旧账号或带占位符的样稿作为成稿交付。

用户明确指定二维码组件时，预览直接使用所选快照，保留原图、边框、动图及图文布局。若当前展示的是模板示例，请在交付说明里标明，并在组件根节点加 data-template-demo="qr"。拿到用户自己的二维码后仅替换对应图片和账号文案，再移除示例标记。
